Entroversu transmission protocol

Privacy

Entroversu uses deliberately minimal, privacy-focused measurement. No visitor accounts, advertising profiles or individual listening histories are created.

Public counters

Signals Received is an image badge supplied by hits.sh. It counts requests for that badge as page-load signals. The provider states that the service uses no cookies, fingerprinting or personal-data tracking.

Entities Entered is an approximate browser count. After the first successful entry, this site stores only the local value yes under entroversu.entity-entered.v1 in the browser. No unique identifier is created. The Cloudflare service operated for Entroversu stores only one aggregate total. Clearing local site data removes the marker.

Private aggregate analytics

Entroversu uses cookieless Cloudflare Web Analytics. It provides aggregate information such as visits, page views, requested paths, referrer hosts, countries, device and browser categories, page-load performance and Core Web Vitals.

Cloudflare states that Web Analytics does not collect or use visitors' personal data and does not track individual users across websites. Entroversu can see aggregate reports, not personal visitor histories.

Hosting and external services

This website is hosted through GitHub Pages. As with any website delivery, the hosting and network providers process technical requests required to serve the pages. Links to Spotify, Apple Music, YouTube and other external services only transfer you to those providers when selected.
